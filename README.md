# Yoav Mayer

**AI Solutions Engineer.** Hands-on AI agents, automation and integrations, without breaking what works.

I fix the manual work that eats a team's week: data re-entered from one system into another, reports built by hand, checks nobody automated. Often a script or a simple integration is enough. When it needs more, I build it the way I built test systems for a production line: tested, with a record of every step.

Independent since March 2026, based in Haifa. Before that, seven years leading the automation and software infrastructure team at Arad Technologies: the R&D automation lab (over 70% of the firmware team's regression testing automated), the production-line testers, and a calibration platform that made calibration at least 4x faster.

## Selected work

- **CRM to invoicing integration for a small business:** each invoice is issued from the CRM record with no retyping, every record is logged, and a deal already invoiced is refused. Cut over 85% of the manual invoicing work.
- **[Babysitter observer dashboard](https://github.com/YoavMayer/babysitter-observer-dashboard):** the activity dashboard for Babysitter, an open-source framework for running AI agents, merged upstream and published on [npm](https://www.npmjs.com/package/@yoavmayer/babysitter-observer-dashboard).
- **Live translation at a medical conference:** visiting doctors heard and read Hebrew lectures in English on their phones within seconds, with medical terms checked against a glossary.
- **[podcast-intel](https://github.com/YoavMayer/podcast-intel):** open-source Python pipeline that turns podcast episodes into transcripts, speaker labels and a quality score.
